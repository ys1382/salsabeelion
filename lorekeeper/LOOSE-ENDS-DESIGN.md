# LoreKeeper — loose ends vs planned-later (verdict)

**Status:** Layer 2–3 shipped (owner-only).

## Problem

Writers mix **accidental contradictions** (fix now) with **intentional gaps** (Act 3 not drafted, climax TBD). Ask should not treat both as "canon conflict."

## Verdict: three layers (in build order)

### Layer 1 — Writer tags and habits (no code required)

Use note tags or title prefixes the writer controls:

| Label | Meaning | Example |
|-------|---------|---------|
| `TODO fix` / `fix:` | Accidental contradiction to resolve | "fix: Etherei's eye color" |
| `planned` / `Act 3 — not drafted` | Intentional gap | "planned: climax alliance" |
| `draft only` | May change | scene beats not locked |

Ask habits: name the work; use audit wording only when reviewing fixes (`discrepancies`, `things to fix`).

### Layer 2 — Ask routes (build after recall #3–4 stable)

| Route | Trigger | Behavior |
|-------|---------|----------|
| **Flagged to fix** | Audit + notes tagged `fix` / `TODO fix` | List only tagged lines; no invented conflicts |
| **Marked for later** | "What's not written yet" / `planned` tags | Honest gaps from labels only |
| **Canon audit** | Existing audit route | Contradictions on **saved facts** without `planned` tag |

Never infer story structure (acts, climax) without writer labels.

### Layer 3 — Draft vs notes dual + doc update cadence (shipped)

When Ask finds a **conflict between main draft and notes** (not `planned:` gaps):

1. **This is what the main draft says:** (summary)
2. **This is what your notes say:** (summary below)

No winner, no scolding, no AI rewrite. Doc page shows a rare **Update document?** bar (~every 3 days) so writers can paste newer manuscript by hand (e.g. from Docs); **Don’t show me this again** + short Feedback link for custom schedule. No Google Docs import.

Also still optional later:

- Same-name collision checks (already partial in aliases)
- Cross-note fact compare beyond spouse/role when both lack `planned`

## Out of scope unless approved

- Auto-detect "this looks like a plot hole" without tags
- Shared contradiction database across accounts
- AI suggesting fixes to canon
- Google Docs / Drive import into LK

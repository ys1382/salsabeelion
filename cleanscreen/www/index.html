CleanScreen Search

Text-first filtered web search · from the Halalit team

Owner beta — not public. Kid mode (default, roughly ages up to 13): hand-vetted destinations plus filtered open-web text. Only public, school-standard, or owner-vetted sites are on the kid list — not whole stores or random locals. Parent mode (14+ / adult when gated): adds news, forums, shopping, gaming publishers, Wikipedia, AI, and more — still no streaming, fanfic, fanservice hubs, or bypass tools. Fewer results is intentional. Search filtering only for now; kidsproof parent unlock is on the roadmap.

Parents and kids can always send private notes (site suggestions, too strict, bad results). Notes do not auto-change lists — owner reviews them. Parent surveys for borderline sites are planned, not live yet.

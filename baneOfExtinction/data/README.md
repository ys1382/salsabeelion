# Bane of Extinction — data files

## `us_riis_lookup.json`

Compact lookup built from the **U.S. Geological Survey** United States Register of Introduced and Invasive Species (**US-RIIS**) ver. 2.0.

- **DOI:** https://doi.org/10.5066/P9KFFTOD
- **License:** CC0 1.0 (public domain)
- **Rebuild:** `python3 baneOfExtinction/scripts/build_us_riis_lookup.py /path/to/USRIISv2_MasterList.csv`

Used only for educational captions (introduced / invasive in AK, HI, or the contiguous U.S.). Not a legal noxious-weed list.

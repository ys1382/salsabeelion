Context Help

Slip stitch on the same piece

When you use this

To move position quietly, finish a decorative edge, or close a small gap without adding height.

What you are joining/working into

You work into stitches that belong to the same fabric panel.

Step-by-step explanation

  1. Insert hook into target stitch.
  2. Yarn over and pull through stitch and loop on hook in one motion.
  3. Keep tension relaxed to avoid puckering.

How it differs from the basic stitch

Basic slip stitch definition is the mechanics only; this context focuses on repositioning within one fabric.

Common mistakes

  • Pulling too tight and shrinking the edge.
  • Using slip stitch where structural height is needed.

Slip stitch (sl st)

Slip stitch to join rounds

When you use this

At the end of a worked round to close the round before the next instruction.

What you are joining/working into

You join the final stitch of the round to the first stitch or chain of the same round.

Step-by-step explanation

  1. Locate first stitch/ch of the round.
  2. Insert hook into that point.
  3. Yarn over and pull through both loops.

How it differs from the basic stitch

Same stitch motion, but placement is precise so the seam line stays clean.

Common mistakes

  • Joining to wrong stitch and shifting stitch counts.
  • Forgetting marker before join.

Slip stitch (sl st)

Slip stitch joining two edges

When you use this

To connect two separate edges (seam, closure, ribbing attach) with a flexible join.

What you are joining/working into

One stitch from edge A and one matching stitch from edge B.

Step-by-step explanation

  1. Align edges and insert hook through both target stitches/loops.
  2. Yarn over and pull through both layers and loop on hook.
  3. Repeat evenly so edges do not twist.

How it differs from the basic stitch

The difference is two-layer placement and alignment, not stitch mechanics.

Common mistakes

  • Mismatched stitch pairing causing ripple.
  • Joining with too much tension and reducing stretch.

Slip stitch (sl st)

Slip stitch through both layers

When you use this

When pattern says join through both layers for stronger seam stability.

What you are joining/working into

Top loops/front loops from two stacked layers or folded fabric.

Step-by-step explanation

  1. Hold layers aligned.
  2. Insert hook through both specified loops.
  3. Yarn over and pull through all loops in one pass.

How it differs from the basic stitch

Basic slip stitch can be one-layer; this context requires two-layer penetration each time.

Common mistakes

  • Catching only one layer and leaving gaps.
  • Skipping paired stitches.

Slip stitch (sl st)

Joining a beanie brim with slip stitches

When you use this

After brim/ribbing section is complete and you need to connect it to beanie body.

What you are joining/working into

Brim edge stitches and matching beanie body edge stitches.

Step-by-step explanation

  1. Match stitch landmarks around circumference.
  2. Insert through one brim point and one body point.
  3. Slip stitch around while checking alignment every few stitches.

How it differs from the basic stitch

This is structural attachment, not decorative traveling.

Common mistakes

  • Uneven stitch matching leading to puckers.
  • Not checking circumference fit before full join.

Slip stitch (sl st)

Attaching ribbing to a hat body

When you use this

For hat constructions where ribbing is made separately then attached.

What you are joining/working into

Ribbing row edges into hat body foundation/edge stitches.

Step-by-step explanation

  1. Mark quarter points on both pieces.
  2. Align quarter points first.
  3. Use slip stitches between markers, adjusting spacing evenly.

How it differs from the basic stitch

Focus is distribution and fit around circumference, not single-stitch execution.

Common mistakes

  • Attaching without distributing ease.
  • Skipping marker-based alignment.
